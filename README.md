# Automatizacion QA - Saucedemo

Proyecto de automatizacion de pruebas realizado con python para el curso de Talento Tech

## Tecnologias usadas
- Python
- Selenium
- Pytest
- Git
- Github

## Instalacion

Instalar las dependencias:
    ```python
    pip install selenium
    ```
    
    ```python
    pip install pytest
    ```

    ```python
    pip install pytest-html
    ```

## Ejecucion   
    ```python
    python -m pytest
    ```

## Casos de prueba
-El inicio de sesión exitoso de los usuarios.
-La correcta carga y visualización del catálogo de productos (inventario).
-La funcionalidad principal del carrito de compras (selección y agregación de productos).
